Psito 3D

Landscapes like the 90s.

Drag the sun across the sky, roll a new world with a die, melt chrome balls into each other and watch the picture sharpen while you look at it. For Linux and Windows. No ads, no telemetry and no account.

Install Source code

What it does

  • A sun you drag on a dial of the sky, from noon to sunset to night
  • Surprise me: a whole new world from one seed
  • Terrains from built-in shapes, from Lua plugins, or from a picture, where white is high
  • The endless sea, fog, valley mist, haze and clouds
  • Balls, boxes, cones and rings in chrome, gold, glass or clay, added, carved or melted together
  • Filters of 256 colours or a tube screen, themes, undo, and pictures saved as PNG

Install

Windows

Windows 10 (1809 or newer) or Windows 11, on x64. It does not ask for administrator rights.

Download the installer

SmartScreen may warn about an unknown publisher, because the installer is not signed with a paid certificate: choose More info, then Run anyway.

Debian, Ubuntu, Mint

Debian 13, Ubuntu 24.04, Mint 22 or newer, on amd64. It updates along with the system.

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://francisceioseph.github.io/psito-3d/psito-3d.asc | sudo tee /etc/apt/keyrings/psito-3d.asc >/dev/null
printf 'Types: deb\nURIs: https://francisceioseph.github.io/psito-3d\nSuites: stable\nComponents: main\nArchitectures: amd64\nSigned-By: /etc/apt/keyrings/psito-3d.asc\n' | sudo tee /etc/apt/sources.list.d/psito-3d.sources >/dev/null
sudo apt update
sudo apt install psito-3d

Fedora

On x86_64. It updates along with the system. The first install asks you to accept the signing key.

sudo curl -fsSL -o /etc/yum.repos.d/psito-3d.repo https://francisceioseph.github.io/psito-3d/psito-3d.repo
sudo dnf install psito-3d

From the source

On any system with Rust and a GPU with Vulkan, Metal or DirectX 12, macOS included.

git clone https://github.com/francisceioseph/psito-3d
cd psito-3d
cargo run --release
